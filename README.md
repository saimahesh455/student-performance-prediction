# Student Performance Prediction System

## Overview

A Machine Learning-based web application developed to predict student math performance using multiple regression models. The application provides model comparison, evaluation metrics, interactive visualizations, and real-time predictions through a Streamlit interface.

## Features

* Predict student math scores using Machine Learning models
* Compare multiple regression algorithms
* Interactive data visualization and performance metrics
* Download prediction results as CSV
* Real-time user input prediction system
* Streamlit-based responsive interface

## Tech Stack

* Python
* Streamlit
* Pandas
* NumPy
* Scikit-Learn
* Matplotlib
* Seaborn

## Models Used

* Linear Regression
* Ridge Regression
* Lasso Regression
* K-Nearest Neighbors Regression
* Decision Tree Regression
* Random Forest Regression

## Installation

Clone the repository:

```bash
git clone https://github.com/saimahesh455/student-performance-prediction.git
cd student-performance-prediction
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
